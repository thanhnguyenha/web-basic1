CSS

Trang hướng dẫn học CSS

Học cấu trúc trang web từ nền tảng — đọc hướng dẫn, viết mã thật, và xem kết quả ngay trên trình duyệt.

Bắt đầu học
index.html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <title>Học HTML</title>
  </head>
  <body>
    <h1>Xin chào!</h1>
  </body>
</html>

Danh sách bài học

Mỗi bài gồm hướng dẫn ngắn, khung soạn thảo mã, và phần xem trước trực tiếp. Checkbox đánh dấu bài bạn đã hoàn thành.

  • Bài 1: CSS trong thẻ style và CSS inlineViết CSS bằng thẻ style, thuộc tính style inline, và hiểu kế thừa màu chữ.
  • Bài 2: CSS file độc lập, độ ưu tiên và !importantLiên kết file .css bằng thẻ link, thứ tự ưu tiên cascade và từ khóa !important.
  • Bài 3: Ngữ pháp CSS chungCấu trúc selector { thuộc tính: giá trị; }, chú thích và gộp selector.
  • Bài 4: Cách viết mã màu trong CSSDùng tên màu, mã hex và hàm rgb()/rgba() để đặt màu chữ hoặc nền.
  • Bài 5: Selector (1): tên thẻ, *, class, idChọn phần tử theo tên thẻ, selector toàn cục, class và id.
  • Bài 6: Selector (2): con trực tiếp, con cháu, kết hợpDùng >, khoảng trắng và selector ghép nhiều điều kiện.
  • Bài 7: Selector (3): trạng thái của thẻPseudo-class :hover, :focus, :active để định dạng theo tương tác.
  • Bài 8: Định dạng văn bảncolor, text-align, letter-spacing, text-decoration, text-transform.
  • Bài 9: Định dạng nền và font chữbackground / background-color và các thuộc tính font.
  • Bài 10: Kích thước (1): width, height, đơn vịĐặt width/height với px, %, rem, vh và các đơn vị khác.
  • Bài 11: Kích thước (2): min/max width & heightGiới hạn kích thước bằng min-width, max-width, min-height, max-height.
  • Bài 12: Box model: margin, padding, borderHiểu và thực hành mô hình hộp của phần tử HTML.
  • Bài 13: Flexbox (1): trục chính và căn chỉnhdisplay:flex, flex-direction, justify-content, align-items.
  • Bài 14: Flexbox (2): flex, wrap, gap, align-selfCo giãn mục con, xuống dòng, khoảng cách và căn riêng một mục.
  • Bài 15: Định dạng bảngborder, border-collapse, hover dòng và màu dòng chẵn/lẻ.
  • Bài 16: Biến CSSKhai báo --bien trong :root và dùng lại bằng var().
  • Bài 17: Position (1): absoluteposition relative/absolute với top, right, bottom, left.
  • Bài 18: Position (2): fixedNeo phần tử theo viewport bằng position: fixed.
  • Bài 19: Grid (1): display grid & templateTạo lưới bằng display:grid và grid-template-columns/rows.
  • Bài 20: Grid (2): grid-column & grid-rowCho ô chiếm nhiều cột/hàng trên lưới.
  • Bài 21: Responsive (1): viewport & media queryMeta viewport và @media theo độ rộng màn hình.
  • Bài 22: Hiệu ứng (1): transitionChuyển đổi mượt các thuộc tính CSS theo thời gian.
  • Bài 23: Hiệu ứng (2): transformXoay, phóng, dịch phần tử bằng transform.
  • Bài 24: Hiệu ứng (3): keyframesTạo animation lặp bằng @keyframes và animation.
